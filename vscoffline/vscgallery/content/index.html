A signature asset is not proof of verification. The mirror preserves original VSIX and signature bytes; VS Code performs the signature check when installing. Local download checksums only detect changes to mirrored files.

Air-gap setup and installation checks
  1. Run the sync service on an Internet-connected system. Transfer the complete artifacts folder, including signature archives and metadata.
  2. Route the required VS Code hostnames to your gallery and configure a certificate issued by your organization. Do not install the old bundled certificate chain.
  3. Keep extension signature verification enabled. For failures, collect the exact VS Code version, extension ID/version, target platform, and Shared log error code.
  4. Extensions may need external language servers, runtimes, or dependencies. Mirroring a VSIX alone does not guarantee full offline operation.

This UI does not apply DNS, certificate, domain, or client configuration changes.
